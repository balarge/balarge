## Hakkımızda

**BAL AR-GE**, Batman Anadolu Lisesi öğrencilerinin bilimsel araştırma, inovasyon ve proje üretimi amacıyla bir araya geldiği bağımsız bir öğrenci araştırma grubudur. Fikir aşamasından prototipe kadar tüm araştırma ve mühendislik süreçlerini ekip çalışmasıyla yürütür, elde ettiğimiz bulguları ve geliştirdiğimiz yazılımları okul topluluğuyla paylaşırız.

```rust
// bal-arge/src/team.rs

pub struct Team {
    pub name:    &'static str,
    pub school:  &'static str,
    pub city:    &'static str,
    pub members: u8,
    pub status:  &'static str,
    pub focus:   &'static str,
    pub method:  &'static str,
}

pub const BAL_ARGE: Team = Team {
    name:    "BAL AR-GE",
    school:  "Batman Anadolu Lisesi",
    city:    "Batman, Türkiye",
    members: 7,
    status:  "Bağımsız öğrenci araştırma grubu",
    focus:   "Araştırma, Tasarım, Yazılım, Mühendislik",
    method:  "Fikirden prototipe, ekip çalışmasıyla",
};
```
